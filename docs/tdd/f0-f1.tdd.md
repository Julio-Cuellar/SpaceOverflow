## 1. Recorridos de usuario (derivados del plan)

1. Como **Dev B**, quiero un bus en memoria con la misma interfaz que el outbox, para desarrollar Conocimiento sin esperar a A.
2. Como **desarrollador**, quiero que los módulos no puedan importar los internos de otros, para que cada uno tenga un solo dueño.
3. Como **sistema**, quiero guardar estado y evento en una sola transacción, para no perder ni duplicar eventos.
4. Como **sistema**, quiero entregar cada evento a sus consumidores al menos una vez, con reintentos y sin repetir trabajo ya hecho.
5. Como **operador**, quiero ver cuántos eventos están pendientes o muertos y cuánto retraso hay, para detectar fallos.

## 3. Incidencias durante el ciclo (tal como ocurrieron)

1. **Primer GREEN parcial de F0: 80 pasaron y 2 fallaron.** `import-linter` avisó de que los patrones `ignore_imports` no tenían coincidencias (aún no hay imports entre módulos). Se declaró `unmatched_ignore_imports_alerting = "none"` y quedaron 82 en verde.
2. **mypy estricto: 16 errores iniciales.** Causas: el campo `type` del sobre ocultaba `type[P]` dentro de la clase, `dict` invariante en el registro, `asyncpg` sin stubs, `2 ** n` tipado como `Any` y `RowMapping` frente a `Mapping`. Todos corregidos sin relajar el modo estricto.
3. **Puerto 5432 ocupado** por `clinerya-postgres` (otro proyecto). No se tocó. La base de este proyecto usa el puerto **5433** (variable `SPACEAPP_DB_PORT`).
4. **`make` no está instalado.** Se mantiene el `Makefile` y se añade `scripts/check.sh`, que hace lo mismo sin `make`.
5. **Docker Desktop estaba apagado.** Se arrancó el servicio de usuario `docker-desktop` (sin habilitarlo para el inicio).
