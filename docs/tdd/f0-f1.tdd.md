## 1. User journeys (derived from the plan)

1. As **Dev B**, I want an in-memory bus with the same interface as the outbox, so I can develop Knowledge without waiting for A.
2. As a **developer**, I want modules to be unable to import the internals of other modules, so each one has a single owner.
3. As the **system**, I want to save state and event in a single transaction, so events are neither lost nor duplicated.
4. As the **system**, I want to deliver each event to its consumers at least once, with retries and without repeating work already done.
5. As an **operator**, I want to see how many events are pending or dead and how much lag there is, so I can detect failures.

## 3. Incidents during the cycle (as they happened)

1. **First partial GREEN of F0: 80 passed and 2 failed.** `import-linter` warned that the `ignore_imports` patterns had no matches (there are no imports between modules yet). `unmatched_ignore_imports_alerting = "none"` was declared and 82 went green.
2. **Strict mypy: 16 initial errors.** Causes: the envelope's `type` field hid `type[P]` inside the class, invariant `dict` in the registry, `asyncpg` without stubs, `2 ** n` typed as `Any` and `RowMapping` versus `Mapping`. All fixed without relaxing strict mode.
3. **Port 5432 in use** by `clinerya-postgres` (another project). It was not touched. This project's database uses port **5433** (variable `SPACEAPP_DB_PORT`).
4. **`make` is not installed.** The `Makefile` is kept and `scripts/check.sh` is added, which does the same without `make`.
5. **Docker Desktop was off.** The `docker-desktop` user service was started (without enabling it at startup).
